What this demonstrates

Designed for an operator’s point of view

Coordination

One task_id connects Inbox, Outbox, Status, and Results so handoffs remain traceable across orchestrators.

  • Dat Dao: owner and final authority
  • BigBoy: Hermes executive orchestration
  • MiuMiu: external engineering orchestration

Operations

The local demo turns system concepts into inspectable operator workflows rather than a static mockup.

  • Kanban work ownership and task detail
  • Agent status, hierarchy, cron, and runtime evidence
  • Explicit [user-input] recovery path

Safety boundary

The public portfolio clone is intentionally disconnected from live Hermes, Mnemosyne, Obsidian, credentials, and machine telemetry.

  • Deterministic in-memory demo data
  • Local Python preview server
  • Public SVG diagrams for GitHub rendering
